# DotLog 0.1.15 界面与插件边界

目标是常驻 Windows 的个人时间记录工具。主界面保留时间线、真实计时和记录操作，不做宣传页。番茄功能由独立 JSON 插件提供页面、标签切换和动作编排；宿主只提供经授权的本机连接、导入、对比接口。未安装或未启用插件时，不创建入口、不连接番茄。

视觉基线：窗口底色 #f6f7f9，内容 #ffffff，正文 #20242b，次级文字 #626b78，边线 #dce1e7，强调色 #315b9b。深色沿用相同层级，七套主题保持可选。字体使用 Windows 系统正文和中文 UI 字体；仅计时数字使用等宽数字。正文 14px、说明 12px、页标题 20px、计时 32px。

布局以左侧导航、主工作区、今日统计栏为固定结构。页标题、工具栏、列表左边缘对齐；主操作高度 36–40px，普通按钮 32px。圆角依层级使用 4/6/8px；不对每条信息重复套卡片。

主界面：

    导航 | 日期与当前状态                 | 统计
         | 计时状态              记录操作 |
         | 时间线标题              筛选   |
         | 时间刻度 — 实际记录            |

插件页面：

    番茄联动                         已启用
    实时记录 | 历史数据
    连接状态    当前任务       计时状态
    主操作 / 次操作
    待补记列表：记录 → 备注 → 保存/跳过

检查标准：单一侧边栏开关；隐藏不等于停用；停用/卸载才停止运行；旧历史开关不再产生另一入口。状态显示实际连接结果。所有主题保持文字可读，对 1120×760、最小窗口和较宽窗口检查溢出、边距、对齐、按钮与输入框尺寸。真实数据库与模拟环境证据分别说明。

方法采用本地安装的 Frontend Design 技能，来源 anthropics/skills 的 skills/frontend-design，安装时固定提交 ca45fc496a3436251f191354091d557da31c15b5。已先审阅设计方向：不采用宣传性大标题、重复圆角卡片或人为装饰编号，突出时间线与记录操作本身。
