# 打点 DotLog · 界面与组件规格

版本：v0.1 ｜ 技术：React 19 + TypeScript + Vite ｜ 组件库：自建（`packages/ui`），无重型 UI 框架

---

## 1. 页面与导航

侧栏 5 个入口，顺序固定：

| 页面 | 主要内容 | 关键动作 |
|---|---|---|
| 今天 | 当前状态、大按钮、全天时间线、空白区间、今日统计 | 打点、补记、拖拽边界、补录 |
| 历史 | 月历、列表、搜索与筛选 | 定位、批量编辑、导出 |
| 分析 | 日/周/月趋势、分类占比、完整率 | 切换周期、下钻明细 |
| 集成 | 插件卡片、权限、同步状态、失败记录 | 安装/启停、配置、重试 |
| 设置 | 快捷键、记录规则、提醒、外观、备份、隐私 | 即时保存与验证 |

“今天”页是默认页，占用 90% 使用时间。窗口关闭 = 隐藏到托盘，不退出。

## 3. “今天”页

### 3.1 大按钮区

| 状态 | 主按钮文案 | 次按钮 | 说明 |
|---|---|---|---|
| 未开始 | 开始打点 | — | 点击创建起点 |
| 记录中 | 打点 | 暂停 / 结束记录 | 显示“已记录 42 分钟”（不是裸计时数字） |
| 暂停中 | 继续 | 补录 | 提示“空白 12 分钟” |
| 待补记 | 保存补记 | 跳过 | 补记框浮出时主按钮次之 |
| 需恢复 | 处理异常记录 | 诊断 | 阻塞其它操作 |

规格：主按钮高度 56，圆角 12，主色填充；计时用 `--font-mono` 等宽数字防跳动；快捷键提示 `Ctrl+Alt+Space` 以小字附在按钮下方。

### 3.2 时间线

- 纵轴：默认展示 `[day_start, now]`，可滚到全天；比例 `1 分钟 = 1.2 px`，缩放下限 0.6、上限 3。
- 轴刻度：每小时一条细线，左侧 56 px 显示 `04:00` 等；当前小时高亮。
- 段卡片：
  - 高度 = 时长 × 比例，最小 18 px（< 30 分钟时标题单行截断）。
  - 颜色取分类色（无分类用中性灰）；左侧 3 px 色条 + 浅色背景，不用大面积饱和色。
  - 内容：标题（缺失显示“未命名”斜体）、时长、标签 chips（最多 3 个，超出显示 +N）。
  - 悬停显示操作：编辑、拆分、删除；右侧显示专注标记。
  - 拖拽上下边缘改起止（步进 1 分钟，按住 Shift 5 分钟）；拖拽时显示吸附时间气泡。
- 空白块：虚线边框 + “空白 32 分钟” + “补录”按钮；仅展示 ≥ 2 分钟的间隙（`stop` 模式下的几秒间隔视觉上并入相邻段，但统计仍按真实空白计算）；连续空白 > 2 小时折叠为“长空白 3 小时（休息？）”。
- 现在线：1 px 强调线 + 右侧“现在 14:32”。
- 重叠冲突：编辑时若与邻段冲突，冲突段显示红色描边并在气泡中给出“裁剪 / 取消”。

### 3.3 今日统计栏

| 卡片 | 内容 |
|---|---|
| 记录总时长 | 大数字 + 相对昨日变化 |
| 有效记录 | 数字 + 有效/记录比例 |
| 专注时长 | 数字 + 段数 |
| 空白时长 | 数字 + “去补录”链接 |
| 记录完整率 | 细进度条（不用环形堆叠） |
| 分类占比 | 自绘环形图 + 图例（Top 4 + 其它） |

原则：所有数字可点击，点击后时间线过滤到对应段集合。

### 3.4 补记浮层

- 位置：主按钮右下方，宽 400，最大高 420；小窗口时居中为模态。
- 字段：标题（单行，自动聚焦）、标签（最近 8 个 + 搜索）、备注（2 行，可展开）。
- 展示本次段时间范围与时长，右上角显示“第 3 次打点”。
- 操作：`Enter` 保存、`Shift+Enter` 换行、`Esc` 跳过、点击外部保存草稿。
- 跳过/关闭后段仍保留（空标题），统计中不计“有效时长”。
- 5 秒内无输入自动保存一次草稿（防止误关丢内容）。

## 4. 其它页面

### 4.1 历史

- 月历：每天单元格显示有效时长热力（4 档强度）；点击进入该日详情。
- 列表：按时间倒序，支持关键词、分类、标签、专注筛选。
- 批量：框选后批量改分类/标签/删除；操作前提示影响条数。
- 导出：按范围导出 JSON/CSV，弹出保存对话框。

### 4.2 分析

- 周期切换：日 / 周 / 月；顶部区间选择器。
- 主图：堆叠柱（按分类）或折线（记录/有效/专注），纯 SVG。
- 辅助：分类占比环形图、完整率趋势、最长专注段。
- 下钻：点击某柱 → 右侧抽屉列出该区间段。

### 4.3 集成

- 插件卡片：名称、版本、能力标签（读时间段/联网/写标签）、开关、状态。
- 首次启用联网插件：模态说明“将发送哪些字段”，需确认。
- 配置区由 manifest 的 `settingsSchema` 生成表单；密钥输入单独标注“存入系统钥匙串”。
- 失败记录表：时间、事件、尝试次数、错误摘要、重试按钮。
- 空状态：说明“核心功能无需任何集成”。

### 4.4 设置

分组：快捷键 / 记录规则 / 提醒 / 外观 / 数据与备份 / 隐私 / 关于。

- 快捷键录制器：按下组合键即时试注册；冲突时红字“已被其它程序占用”。
- 日期边界：默认 04:00，改动后提示“仅影响展示与统计归属，不改原始记录”。
- 记录模式：`stop`（默认）/ `chain`，附一句差异说明。
- 备份：位置、保留策略、立即备份、恢复（二次确认）。
- 隐私：联网插件列表与最近一次联网时间。

## 5. 键盘与托盘

| 场景 | 快捷键 |
|---|---|
| 全局打点 | `Ctrl + Alt + Space`（可改） |
| 撤销最近打点 | `Ctrl + Z`（15 秒内） |
| 保存补记 | `Enter`（焦点在标题）/ `Ctrl + Enter` |
| 关闭浮层 | `Esc` |
| 前一天 / 后一天 | `←` / `→`（时间线聚焦时） |
| 打开搜索 | `Ctrl + K`（历史页，M2） |

托盘：

- 图标随状态变化（空闲 / 记录中）。
- Tooltip 与标题：`打点 · 42 分钟`。
- 左键：打点（记录中）或开始（空闲）。
- 右键菜单：开始/打点、暂停、结束记录、打开主界面、设置、退出。

## 6. 组件与代码组织

```
packages/ui/src/
├── primitives/     Button, IconButton, Input, Textarea, Dialog, Sheet,
│                   Switch, Select, Tag, Tooltip, Toast, EmptyState
├── timeline/       DayTimeline, TimeAxis, SegmentBlock, GapBlock,
│                   NowIndicator, DragHandle, TimeBubble
├── stats/          MetricCard, RingChart, BarChart, TrendChart, CategoryLegend
├── note/           NotePopover, TagPicker
├── layout/         AppShell, SideNav, PageHeader, StatsAside
└── tokens/         theme.css, category-palette.ts
```

- 页面级状态：TanStack Query 缓存 `day:<date>`、`state`、`stats:<range>`；命令成功后按事件失效。
- 临时 UI 状态：Zustand（补记浮层、拖拽中边界、筛选草稿）。
- 组件不自带数据请求；数据由 `features/*` 注入，便于 Storybook/测试。
- 图表全部自绘 SVG，不引入 ECharts/Recharts（ADR-010）。

## 7. 视觉规范

| token | 用途 |
|---|---|
| `--surface` / `--surface-muted` | 页面底色 / 卡片与嵌套区块 |
| `--text` / `--text-muted` | 主文本 / 辅助信息 |
| `--brand` | 主按钮、当前线、选中态 |
| `--danger` | 删除、冲突、失败 |
| `--radius` 8 / `--radius-card` 12 | 控件 / 卡片 |
| 字号 | 正文 14，辅助 12，标题 16，数字用等宽 |

分类色板（8 色，深浅主题各一套，保证 4.5:1 文字对比）：学习、工作、生活、运动、阅读、娱乐、睡眠、其它。用户可自定义，但默认不随机生成，避免刺眼。

动效：仅用于状态变化（浮层 120 ms 淡入、段保存 120 ms 高亮），尊重 `prefers-reduced-motion`。

## 8. 文案基线（中文）

| 场景 | 文案 |
|---|---|
| 空闲 | 开始打点 |
| 记录中 | 打点 |
| 暂停后 | 继续 |
| 短段提示 | 刚记录了 8 秒，要撤销这次打点吗？ |
| 撤销过期 | 已超过 15 秒，请到时间线直接修改 |
| 长空白 | 系统休眠了 1 小时 20 分，这段时间计入吗？ |
| 跨日 | 昨天有一段未结束的记录，怎么处理？ |
| 空日历 | 这天还没有记录，点“补录”添加 |
| 无集成 | 所有数据都在本机，不装任何插件也能完整使用 |

## 9. 无障碍与可用性

- 所有可点击元素有可见焦点环（2 px，`--brand`）。
- 主按钮 ≥ 44 × 44；时间线段可键盘选中（Tab）并用 `Alt+↑/↓` 调边界。
- 颜色不作为唯一信息：分类同时显示名称，空白块用纹理+文字。
- 错误提示与 toast 使用 `role="status"`，不打断输入。
