## 1. 项目概述

DotLog（打点）是一个**本地优先**的桌面时间记录应用：

- 一键「打点」开始/结束计时，形成时间记录段（Segment）
- 今日时间线可视化、历史浏览、分类统计
- 段关闭后可自动发布到自托管 Memos 实例
- 应用内嵌 Memos 浏览页（iframe）
- 番茄Todo 本地数据导入、与 DotLog 记录做覆盖率对比、智能分析
- 可选 AI 助手（OpenAI 兼容接口）
- 数据全部存本地 SQLite，令牌存操作系统钥匙串，不上传云端

## 4. 关键架构决策

### 4.1 Tauri 2 权限门控（易踩坑）

前端调用任何窗口/事件 API 前，必须在 `apps/desktop/src-tauri/capabilities/default.json` 声明对应权限，否则**调用被静默拒绝**（Promise reject，UI 无报错）。当前权限集：

```json
core:default,
core:window:allow-start-dragging, allow-minimize, allow-toggle-maximize,
allow-set-fullscreen, allow-is-fullscreen, allow-close
```

> 教训：v0.1.0 全屏按钮失效就是因为漏声明 `allow-set-fullscreen`。v0.1.1 已补。注意该版本 Tauri **没有** `allow-on-resized` 权限（resize 事件归 `core:event`，`core:default` 已含）。

### 4.2 窗口无边框 + 自绘标题栏

`tauri.conf.json` 中 `decorations: false`，标题栏由 `TitleBar.tsx` 自绘，拖拽区用 `data-tauri-drag-region`。窗口默认 1120×760，最小 880×620，响应式布局（侧栏 196px→窄屏 64px 图标态，右栏 ≤980px 隐藏）。

### 4.3 全屏状态同步

Tauri 2 **不存在** `tauri://fullscreen-changed` 事件。`src/lib/window.ts` 的 `onFullscreenChange` 通过 `onResized` + `isFullscreen()` 轮询同步真实状态；`TitleBar.tsx` 不做乐观更新，图标只反映真实状态。

### 4.4 前端 IPC 与浏览器 mock

`src/lib/ipc.ts` 检测 `__TAURI_INTERNALS__`，非 Tauri 环境（纯浏览器预览）走 mock 数据。注意 mock 必须与真实逻辑保持一致（v0.1.0 修过 mock 不一致问题）。

### 4.5 Memos 集成

- 探测：`crates/memos/src/endpoints.rs` 依次尝试 5 个候选路径（`/api/v1/workspace/profile`、`/api/v1/memos`、`/api/v1/status`、`/api/status`、`/api/memo`），覆盖 Memos v0.13–0.22+；2xx=成功，401/403/405=实例可达但令牌问题，404=路径不存在换下一条；全部失败时返回每条路径的真实 HTTP 状态码与响应片段。
- 发布：由 `autoPublish` 配置驱动（`off`/`on_close`/`tagged`），走 outbox 可靠队列。v0.1.0 前 UI 未暴露该配置导致"连接成功但不发布"，已在 `IntegrationsPage.tsx` 补齐 4 个配置项（自动发布/可见性/包含备注/标签规则）。
- 应用内浏览：`MemosPage.tsx` 用 iframe 嵌入实例地址。**已知限制**：若实例设置 `X-Frame-Options: DENY` 则无法内嵌，页面已提供浏览器打开回退。

### 4.6 AI 分析（番茄Todo）

`src-tauri/src/integrations.rs` 中 `parse_chat_content()` 从 OpenAI 响应 `choices[0].message.content` 提取内容并剥除 markdown 代码块包裹。UI 文案统一为「智能分析」（不露出 AI 字样）。

### 4.7 覆盖率计算

`crates/tomatodo/src/compare.rs` 覆盖率先 `.clamp(0.0, 100.0) as u8` 再转换，防止 u8 溢出；有测试 `compare_coverage_clamped_to_100` 守护。

## 6. 构建 / 验证 / 发布流程

```powershell

# 发布（需要 gh 已登录；本机直连 GitHub 需代理）
git add -A; git commit -m "..."; git push
gh release create v<x.y.z> <setup.exe> <portable.exe> --title "..." --notes "..."
```

**已知环境约束**：本机访问 GitHub 需走 HTTP 代理（`HTTPS_PROXY` 环境变量 + 仓库级 `git config http.proxy`）；MSI 打包需在线下载 WiX 常超时，故只用 NSIS。

## 8. 已知问题 / 技术债（请审查者重点关注）

1. **Memos iframe**：目标实例若返回 `X-Frame-Options: DENY`/`frame-ancestors` CSP，内嵌页会空白——当前无自动检测，只有手动回退链接。
2. **Memos 版本适配**：探测覆盖了 v0.13–0.22+，但发布接口只用 v1（`/api/v1/memos`），对更老版本可能不兼容，未实机验证旧版。
3. **autoPublish 默认 off**：用户必须手动在集成页改为「段关闭时自动发布」，无引导提示，可能再次被误认为"集成不可用"。
4. **Esc 退出全屏**：Tauri 真全屏下 Esc 退出依赖系统行为，未做应用级快捷键兜底。
5. **未签名**：安装包无代码签名，Windows SmartScreen 会提示未知发布者。
6. **标题栏跨日导航按钮为 disabled 占位**（`TitleBar.tsx`），功能未实现。
7. **稳定性**：应用未经完整测试，README 已声明；`Cargo.toml` 中 crate 版本（0.1.0）未随 tauri.conf.json 同步到 0.1.1，仅元数据不一致，不影响产物。
