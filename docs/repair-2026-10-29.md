## 暂停、继续与结束：现在的行为

一次记录可以包含多个实际计时片段。暂停关闭当前片段并冻结累计时长，继续创建下一个片段并接着累计；暂停空档保留在时间线中，不计入记录。

例如 09:00 开始，09:20 暂停，09:40 继续，10:10 结束：实际时长为 20+30=50 分钟，暂停的20分钟不计入。时间线上仍能看到两个有效片段和中间的暂停空档。

- 暂停时不弹标题/备注框，不触发 Memos 发布。
- 暂停中可以直接结束，不会把暂停末尾到结束点击之间的时间算进记录。
- 结束（包括主按钮完成当前段）后统一填写一次标题与备注，内容同步到同一次记录的所有片段。
- 继续后秒表显示累计实际时长；今日统计按当日片段计算，避免跨日/多次暂停时重复累计。
- 暂停状态和累计时长持久保存，重启后可以继续；编辑暂停记录不会意外丢失暂停状态。
- 撤销继续会回到暂停；撤销暂停中结束也会回到暂停；连续打点撤销不再违反“只能有一个进行中段”的约束。
- 自动发布等待你保存或跳过结束填写框，等待状态也会保存。填写超过一分钟或退出再打开，不会抢先发布空内容。
- 一次完整记录只排队发布一次；Memos 中的汇总时长为有效片段之和。

schema 3 为已有记录补上会话映射；历史闭合记录保持原状，不擅自猜测并合并旧记录中可能存在的暂停关系。

## Memos：配置一次 Access Token

按照你最后确认的要求实现，不使用账号密码或 iframe 登录。

1. 打开“集成”，在插件目录中添加 Memos。
2. 启用插件，填写实例地址与 Access Token，保存后测试连接。
3. 点击侧边 Memos，程序自动复用这些配置和系统钥匙串中的令牌。

侧边现在是 DotLog 内置 Memos 客户端，支持读取、分页、搜索已加载内容、新建、编辑与确认删除。未发布的正文自动保存为本机草稿，按实例和用户标识隔离。令牌只在 Rust 后端使用，不通过 URL 或接口响应传给界面。

身份验证使用 Memos 的受保护用户接口，不再把公开 profile 返回200当作令牌有效的证据。支持探测 /api/v1、当前 /api 和较早版本接口；兼容策略已经加入模拟HTTP测试，不能等同于所有版本均已实机验证。

这是常用记录功能的内置客户端，并非 Memos 完整网站的复制品；附件、关系、评论、设置等高级功能没有全部移植。正文目前以安全纯文本展示，不执行远端 HTML。

自动发布仍单独由“自动发布”选项控制，默认关闭；仅启用浏览不代表自动公开记录。备注是否发送由“包含备注”决定，默认不发送。

## 插件目录

- 已添加插件与可添加目录分开显示。
- 支持添加、移除、重新添加，启用/停用独立控制。
- 移除会停用插件，保留配置、钥匙串凭据及本地记录，方便重新添加；不删除远端 Memos。
- 停用或移除后，已有队列不会继续启动发送；重新添加后仍需手动启用。
- 当前目录提供 Memos、AI 助手、番茄Todo，符合本次选择的内置插件模式。
- 尚不支持导入任意第三方代码包或连接 MCP；目录与安装状态已独立，后续可以扩展。

## 升级与验收

先在旧版“设置→立即备份”，再从托盘退出旧版，安装本次版本。首次启动会把数据库从 schema 2 升为3；升级后的数据库不能直接交给旧版打开，回退时应使用旧版备份。

建议先验证：开始→暂停→继续→结束、重启后继续暂停记录、保存标题后 Memos 发布、插件移除后不发送，以及备份恢复。安装包没有代替你安装，也没有改动你正在使用的数据库。

## 尚需实机验收的边界

没有完成安装后窗口/托盘/快捷键的 Windows 全流程验收、真实休眠/时区切换和7天长测。本地模拟HTTP与源码适配不代表全部历史 Memos 服务均兼容。

Memos 服务器创建成功但响应丢失的极端情形仍可能需要远端对账；本地去重不能证明跨网络恰好一次投递。已发布内容随后在本地被修改或撤销时，本次不会自动删除或覆盖远端已发布内容。

保留这些边界是为了准确区分已验证修复和长期可靠性证据。本版本作为可试用候选版交付。
