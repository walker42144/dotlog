# DotLog 0.1.17 更新与审查报告

## 使用

在当前记录结束后关闭 DotLog，再运行Release 附件中的 `DotLog_0.1.17_x64-setup.exe`。这是正式产品 DotLog（com.dotlog.desktop）的升级包，沿用正式数据目录。安装后在“设置 → 外观”选择主题与动画。番茄联动仍为独立插件，已有 0.4.0 插件无需重装。早期独立预览版属于另一个产品，本包不会合并或删除它。

## 动画

页面切换淡入、按钮按下反馈、控件悬停/聚焦过渡、开关位移、计时状态变化确认、对话框展开。动画仅影响展示，不重建计时器、不改记录时间、不等待动画完成后才保存。页面切换动画会清理，切换系统动态偏好时可取消。新增“减少动态效果”，也尊重系统的减少动态设置。现有补记和提示动画也受该设置控制。

## 本轮审查和修复

人工跟踪检查了前端设置/计时/插件/AI 操作，原生插件权限与生命周期、番茄观察器及状态机，SQLite 事务、恢复和 AI 写入路径；并对整个工作区运行自动测试和静态检查。这是工程审查，不代表形式化证明或每一条路径都做过实机测试。

1. 切换外观会触发计时器全量刷新并清除撤销提示。改为只更新规则与日视图，保留撤销窗口和待补记状态；浏览器操作验证打点后换主题仍显示撤销与补记。
2. 插件对象重新读取会重建 Worker，导致换肤时历史标签页重置。改为按插件 ID、脚本、权限和启用状态决定生命周期；浏览器验证历史页在换肤后保留。
3. 插件页面缺少 activeTab、字段重复 ID、输入类型等完整校验。新增纯校验器，拒绝格式异常和重复字段键；要求当前标签实际存在，草稿索引改用无原型对象，避免特殊标签 ID 引起异常，补充异常输入测试。
4. 插件包的安装预览未验证所有待渲染字段类型，异常 JSON 可能在显示权限预览时导致 React 报错。现在在渲染前检查名称、作者、描述、版本及权限的类型和格式；原生层仍独立校验。
5. 网络响应超过上限会被静默截为 4MB。现在多读一个字节检测溢出并明确拒绝，测试小响应、恰好边界和超过边界。
6. AI 应用建议未走与手动编辑相同的启动恢复前置检查，现已补齐；保留已有 revision 冲突校验。
7. AI 操作加入即时引用锁，避免极短时间连续点击产生重复请求；外观加载/保存失败增加错误处理与切换回退。
8. 窄窗口下后加载的桌面样式挤压侧栏图标；修复图标不可收缩和窄栏内边距，快捷操作入口也避开日期。
9. 依赖审计发现间接 KaTeX 0.16.47，虽然直接依赖已是 0.19.1。统一覆盖到 0.19.1 并重新验证 Markdown/数学渲染测试。相关官方通告：https://github.com/advisories/GHSA-238p-pmpm-9mq7 。

## 尚存限制与告警

cargo-audit 的锁文件检查列出 proc-macro-error、zbus_names、zvariant、zvariant_derive 的停止维护提示，以及 glib 的历史 unsoundness 提示。Windows 目标反向依赖检查未引入 proc-macro-error、glib 或 zvariant；这些来自其他平台的依赖树，未为清空提示而强制跨主版本替换 Tauri 的平台依赖。其他平台发布前仍需单独处理和验证。RustSec 数据库本次提交 ee1a49a2769a24a596afc1c20cb33748d2769586，更新时间 2026-10-29。

npm 的旧依赖声明仍为 KaTeX ^0.16，项目通过 overrides 使用 0.19.1 修复通告；npm ls 会提示超出上游声明范围。干净安装、公式测试和生产构建通过，但仍需跟进上游更新依赖声明，不能据此宣称所有公式都已逐个验证。

本轮视觉操作使用浏览器模拟数据，未操作你的真实记录或替你结束番茄任务；未重新做安装后 WebView2、真实 AI/Memos 服务和长期运行端到端验收。生产构建仍有主包较大的性能提示，不影响构建成功；后续可按页面拆包。自动扫描没有发现漏洞不等同于软件绝无漏洞。

已使用 frontend-design 设计技能，新增 cargo-audit 0.22.2 依赖检查工具；代码审查和数据验证均在本地完成，不需新增云端 MCP 或上传源码。
