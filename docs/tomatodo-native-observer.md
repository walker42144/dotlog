# DotLog 0.1.11 内置番茄观察器

观察器已移入桌面宿主的 Rust 模块 `tomatodo_observer.rs`。宿主直接通过本机 CDP 连接官方番茄，不启动 Node，不运行外部观察器脚本，不开放原来的 19376 辅助服务。插件继续负责联动界面，后台不依赖插件页面保持打开。

首次安装并启用「番茄联动」插件后，后续直接打开 DotLog 会恢复连接。手动暂停联动会持久保存，需在插件里恢复。官方番茄未运行时，DotLog 自动带本机连接参数打开它；若番茄已经以普通方式运行，提示用户在专注结束后正常退出，然后自动重开，不强制中止任务。

内置观察器只读取已验证的官方页面及其计时字段，只允许 127.0.0.1:19275 的页面连接。连接有大小和时间限制，读取错误作为断连处理，不解释为任务结束。连接恢复后继续使用既有会话核对规则。首次接入进行中的正计时从当前时刻开始，不补写历史时间。

默认约 750 毫秒采样一次。正计时开始后自动创建同名第一段；手动结束分段后可独立备注，下一段手动开始并继承任务名。来源手动结束进入休息时收尾，休息与跳过休息均不创建分段。

源码中早期 `scripts/tomatodo-observer.*` 保留为历史诊断工具；0.1.11 安装包和便携包均不携带、不调用这些文件。诊断示例 `tomatodo_observer_probe` 使用与宿主相同的 Rust 模块，只读当前状态，不启动官方番茄，不写 DotLog 记录。
